# Auditoría de frontend — 2026-11-26

## Alcance

Se ejecutó `npm run build` en `app/` con las dependencias existentes. La compilación terminó correctamente con Vite 6.4.6.

## Hallazgos

### Medio — Paquete JavaScript inicial supera 500 kB

El bundle principal minificado ocupa aproximadamente 1.78 MB (534 kB gzip). Vite emite la advertencia de límite de 500 kB. La carga inicial puede ser lenta en redes móviles, especialmente al incluir reportes y exportación de documentos.

**Recomendación:** separar módulos de rutas y dependencias de exportación mediante carga diferida; medir el bundle resultante antes de fijar el criterio de aceptación.

### Medio — Video integrado pesa aproximadamente 31 MB

El build copia el video promocional a un recurso de unos 31.4 MB. Cuando se sirve desde la aplicación administrativa puede aumentar el tiempo y ancho de banda de descarga.

**Recomendación:** revisar compresión y carga diferida del video o servir una versión optimizada.

### Bajo — Imágenes individuales de varias páginas son grandes

El build incluye imágenes PNG de 0.88 MB a 2.30 MB. Esto incrementa la transferencia en las vistas que las usan.

**Recomendación:** generar variantes optimizadas y dimensiones apropiadas para cada vista.

- No se ejecutó una prueba visual ni se afirma rendimiento real en dispositivo.
