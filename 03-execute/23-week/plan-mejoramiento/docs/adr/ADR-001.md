# ADR-001: Mandatory Technology Stack

**Project:** Mobility Aids  
**ADR ID:** ADR-001  
**Status:** Accepted  
**Date:** 2026-11-08

## 1. Context

The Mobility Aids project requires a frontend application, a backend API and a public static presentation website.

The project requirements establish React as the frontend technology and PHP with Laravel as the backend framework.

The implementation must follow the approved project specification and architecture.

## 2. Decision

The project will use the following mandatory technologies:

- **Frontend:** React.
- **Backend:** PHP with Laravel.
- **Infrastructure:** Docker containers.
- **Database:** Must follow the approved architecture and data model.

The public presentation website will be static and independent of the API.

## 3. Rationale

This decision follows the technologies and product requirements established in the instructor's improvement-plan document.

Separating the frontend, backend and infrastructure responsibilities will allow each component to be developed and tested independently.

## 4. Consequences

### Positive consequences

- Clear separation between frontend and backend.
- API-based communication.
- Independent component development.
- Containerized execution through Docker.

### Constraints

- The backend must use Laravel.
- The frontend must use React.
- The implementation must remain consistent with the approved specification.
- No additional technologies will be introduced without architectural justification.

## 5. Compliance

All implementation tasks must respect this decision.

Any proposed change to the mandatory technology stack must be documented and justified.
