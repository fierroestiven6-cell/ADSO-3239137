# ADR-001: Mandatory Technology Stack

**Project:** Mobility Aids  
**ADR ID:** ADR-001  
**Status:** Accepted  
**Date:** 2026-11-08
**Reviewed:** 2026-11-26 (decision unchanged)

---

## 1. Context

The Mobility Aids project requires a frontend application, a backend API, a database infrastructure, and a public static presentation website.

The project requirements establish React as the frontend technology and PHP with Laravel as the backend framework.

The implementation must follow the approved project specification, project constitution, and system architecture.

The execution environment must support containerized infrastructure using Docker.

## 2. Decision

The project will use the following mandatory technologies and architectural components:

- **Frontend:** React.
- **Backend:** PHP with Laravel.
- **Infrastructure:** Docker containers.
- **Database:** Must follow the approved architecture and logical data model. Its specific engine and configuration must be documented through the corresponding architectural decision.
- **Public website:** Static and independent of the application API.

The frontend and backend will communicate through the HTTP API defined in `api-contract.md`.

## 3. Rationale

This decision follows the technologies and product requirements established in the instructor's improvement-plan document and the approved project constitution.

Separating the frontend, backend, database infrastructure, and public website responsibilities allows each component to be developed, maintained, and tested independently.

Using Docker supports a reproducible execution environment and consistent application deployment.

## 4. Consequences

### Positive consequences

- Clear separation between frontend and backend.
- Standardized API-based communication.
- Independent component development and testing.
- Containerized execution through Docker.
- A reproducible infrastructure configuration.

### Constraints

- The backend must use PHP with Laravel.
- The frontend must use React.
- The infrastructure must comply with the containerization requirements.
- The database implementation must remain consistent with the approved architecture and data model.
- The public presentation website must remain independent of the application API.
- The implementation must remain consistent with the approved project specification.
- No changes to the mandatory technology stack may be introduced without architectural justification and documentation.

## 5. Compliance

All implementation tasks must respect this decision.

The project architecture and implementation must maintain consistency with the technologies established in this ADR.

Any proposed change to the mandatory technology stack must be documented in a new or updated Architecture Decision Record, including its justification and consequences.
