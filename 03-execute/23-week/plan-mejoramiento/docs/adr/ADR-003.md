# ADR-003: Historical Records and Logical Deletion

**Project:** Mobility Aids  
**ADR ID:** ADR-003  
**Status:** Accepted  
**Date:** 2026-11-08

## 1. Context

Mobility Aids manages technical aid loans, returns and catalog records.

Historical information must remain available even when catalog information changes.

The project requirements establish that loans and returns cannot be physically deleted and that the catalog must use logical deletion.

Additionally, historical information frozen at the time of an operation must not change when the original catalog record is modified.

## 2. Decision

The system will preserve historical loan and return records permanently.

The following rules must be enforced:

- Loan operations cannot be physically deleted.
- Return operations cannot be physically deleted.
- Technical aids must use logical deletion instead of physical deletion.
- Historical operation data must preserve the relevant information from the time of the transaction.
- Changes to catalog information must not modify previously recorded historical snapshots.

## 3. Rationale

Preserving historical records provides traceability and maintains the integrity of past transactions.

Logical deletion allows the catalog to stop presenting inactive technical aids without destroying historical references.

Historical snapshots ensure that previous operations remain consistent even when catalog information changes.

## 4. Consequences

### Positive consequences

- Preserves transaction history.
- Maintains historical consistency.
- Supports auditing and traceability.
- Prevents accidental loss of operational records.
- Allows inactive catalog items to remain referenced by historical transactions.

### Constraints

- Physical deletion of loans and returns is prohibited.
- Catalog deletion must be logical.
- Historical snapshots must remain unchanged.
- Database relationships must preserve historical integrity.

## 5. Compliance

All persistence operations must respect this decision.

Automated tests must verify that historical records remain unchanged after catalog modifications and that prohibited deletion operations cannot occur.
