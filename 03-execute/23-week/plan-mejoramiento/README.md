# Mobility Aids

## Project Overview

Mobility Aids is an assistive equipment management system designed to manage technical aids, beneficiaries, inventory, loans, and returns.

## Technology Stack

- Frontend: React.
- Backend: PHP with Laravel.
- Database: As specified in the approved architecture.
- Infrastructure: Docker and Docker Compose.

## Project Structure

- `docs/`: Technical documentation and project specification.
- `api/`: Backend application.
- `app/`: Frontend application.
- `page/`: Public static website.
- `infra/`: Infrastructure and database configuration.
- `tool/`: Development and support tools.

## Documentation

The `docs/` directory contains the project constitution, specification, architecture, data model, API contract, development plan, tasks, and Architecture Decision Records.

## Language Convention

- Technical documentation and source code identifiers: English.
- User-facing messages: Spanish.

## Project Status

Initial documentation completed. Product implementation in progress.
