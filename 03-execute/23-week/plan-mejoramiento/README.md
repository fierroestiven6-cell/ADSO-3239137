# Mobility Aids

Este proyecto es la solución del plan de mejoramiento del aprendiz A18, ficha 3239137, dominio mobility-aids.

## Project Overview

Mobility Aids is a technical assistance management system designed to manage assistive devices, beneficiaries, inventory, loans, and returns.

## Project Structure

- `docs/`: Project specifications and technical documentation.
- `api/`: Backend application developed with PHP and Laravel.
- `app/`: Frontend application developed with React.
- `page/`: Public static website.
- `infra/`: Docker infrastructure and database configuration.
- `tool/`: Development and support tools.

## Technology Stack

- Frontend: React
- Backend: PHP and Laravel
- Database: To be defined according to the approved architecture.
- Infrastructure: Docker and Docker Compose.

## Project Documentation

See the `docs/` directory for the complete project specification, architecture, data model, API contract, development plan, tasks, and Architecture Decision Records (ADRs).

## Language Convention

- Source code identifiers and technical documentation: English.
- User-facing messages: Spanish.
